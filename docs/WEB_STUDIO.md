# HotClip Web Studio

独立于 Electron 的本地 Web 切片后台。直接读取全片分析工作流产物，不重新跑 Qwen、Terra 或 Sol。

## 启动

```powershell
pnpm install
pnpm studio:build
pnpm studio "D:/AI/hotclip-runs/full-20261116"
```

打开 <http://127.0.0.1:8767>。开发时在末尾加 `--dev`，端口可通过 `--port=8768` 指定。
Windows 可用隐藏窗口启动器：

```powershell
powershell -ExecutionPolicy Bypass -File tools/start-studio.ps1 -RunRoot "D:/AI/hotclip-runs/full-20261116"
```

支持一次传入多个已分析录播目录。`GET /api/projects` 返回项目 ID，可用 `/?project=<id>` 打开对应项目。当前版本的素材接入入口是分析目录，不是浏览器上传器；录播结构化与模型校核仍由现有分析工作流完成。

每个目录需要：

- `source.json`：原视频路径、文件大小和媒体元信息。
- `selection/interest-candidates.json`：全片兴趣点与建议边界。
- `audit/reviewed-lines.json`：含稳定 ID、原始 ASR、校核文本、时间和疑点的逐句记录。
- `audit/danmaku.json`：可选；直播背景及带原片时间的弹幕事件。

## 操作流程

1. **选片段**：右侧兴趣点与全片时间轴联动。点击兴趣点，在下方局部精调区拖动入点、出点；点击拨钮上方的时间标签可输入 `HH:MM:SS.mmm` 并跳转。拨钮支持方向键。试听入点播放前 10 秒，试听结尾播放末 5 秒，均自动停在选区内。
2. **加入输出列表**：切片有独立的标题、范围和字幕副本。点击队列条目重新调整，更新后保留已有文字修订。可调整顺序或移除。未可靠定位的标记只打开前后 15 秒供试听，必须人工确认范围后添加。
3. **字幕审核**：左侧切换切片，中央播放，右侧逐句查看。点击画面字幕直接编辑；右侧可改文本、改起止时间、查看 ASR 原文及校核原因、回听前后 1 秒并确认此句。未确认疑点会在导出页提示，但不会强制阻止导出。
4. **导出设置**：选择画质/码率、原片/1080P/720P、是否压字幕、是否压直播弹幕。点击“开始导出”才会真正生成切片视频。任务支持进度、取消、下载和失败后重新提交。

修改自动存入该录播目录的 `studio/draft.json`，切换页面和刷新不会丢失已加入队列的切片、字幕及设置。原始分析文件不被改写。冲突保存返回 409，页面提示刷新，避免多个页面静默覆盖。尚未加入队列的临时选区不落盘。

## 预览与输出

首次把录播 FLV 中的 H.264/AAC 无损换装为可随机拖动的 MP4；`+faststart` 整理索引期间仍显示准备中。缓存以源文件路径、大小、修改时间签名区分；再次打开复用。需要约一份原视频大小的额外磁盘空间。当前浏览器预览针对 H.264/AAC 录播，其他编码可能需要另行转码。

浏览器通过 HTTP Range 读取本机文件，无需整段下载后播放。播放器使用原片绝对时间，画面、字幕、弹幕、入出点和导出共用该时间基准。滚动弹幕采用 Canvas，暂停和拖动后根据当前时间重建；浏览器与 ASS 共用保守的不相撞轨道分配。仅渲染普通聊天弹幕；高密度超出轨道容量时跳过拥挤条目，不把礼物、舰长事件伪装成聊天。

播放器“弹幕”开关控制预览；导出设置中的“渲染直播弹幕”控制永久压制，二者独立。自动码率使用 x264 CRF 20，按实际画面复杂度分配；高画质 CRF 17，小体积 CRF 25，手动模式按目标 Mbps 编码。保留原比例与帧率，不将低分辨率素材放大；AAC 192 kbps。

每次导出保存到 `studio/exports/<任务ID>/<序号>/`：

- MP4 视频。
- SRT 字幕（去句读标点，保留 `3.5` 等数字表达）。
- 字幕上下文 CSV：原片/片内时间、原 ASR、审核后文字、是否人工确认、疑点、前后句。
- 上下文 JSON：范围、字幕、背景、兴趣点依据与区间内弹幕。

字幕时间沿用全片 ASR 的片段级时间，人工可以调整；网页编辑不会偷偷再次调用模型或宣称完成新的逐字强制对齐。混合游戏语音、断在句内、长句排版仍应在审核页听看确认。渲染阶段重新编码以实现精确入出点，不采用只能贴近关键帧的直接复制切片。

## 运行边界与维护

- 服务只绑定 `127.0.0.1`，校验 Host、Origin 和写接口会话令牌。它是本机工作台，不是公网多用户服务。
- 所有媒体与下载路径均从注册项目和已完成任务的文件清单解析，不接收任意下载路径。
- 草稿原子替换；导出从提交时的快照运行。重启时将残留运行任务标记失败，保留已生成文件供排查，重新提交即可。
- 导出串行调度，浏览器关闭不停止后端任务。取消终止当前 FFmpeg，保留已经完成的片段；未完成的 `.partial.mp4` 不提供下载。
- `tools/start-studio.ps1` 不会接管或停止已有端口上的进程。服务日志位于 `<RunRoot>/studio/server.out.log` 与 `server.err.log`。

## 验证

```powershell
pnpm studio:check
pnpm typecheck
pnpm exec vitest run src/core/__tests__/studio.test.ts
pnpm studio:build
pnpm studio:test
```

浏览器验收默认使用本机 Microsoft Edge（Playwright `channel: msedge`）。生成独立的 12 秒测试视频和分析数据，测试精确入出点、键盘拨钮、草稿恢复、字幕改字与去标点、实际压制/下载、Range、写接口令牌、并发草稿冲突、错误边界拒绝、弹幕 ASS、取消、无障碍与窄屏。测试不会选择或导出用户录播，截图和验收记录保存在忽略提交的 `studio-test-results/`。

前端遵循 `modern-web-guidance` 的 `slider`、`accessibility`、`forms`：原生 range 保留键盘行为、分开书写各浏览器滑块伪元素、使用 CSS 变量传入百分比避免对新 `attr()`/`progress()` 的硬依赖；原生 dialog 管理焦点；分步导航保留草稿，原生表单与可见标签、错误提示和服务端验证配合。

# HotClip Web Studio

独立于 Electron 的本地 Web 切片后台。直接读取全片分析工作流产物；自动复用已有字词时间，按需对选中片段调用本地 Qwen 强制对齐，不重跑全片识别或模型选题。

## 启动

```powershell
pnpm install
pnpm studio:build
pnpm studio "D:/AI/hotclip-runs/full-20261116"
```

打开 <http://127.0.0.1:8767>。开发时在末尾加 `--dev`，端口可通过 `--port=8768` 指定。
Windows 可用隐藏窗口启动器：

```powershell
powershell -ExecutionPolicy Bypass -File tools/start-studio.ps1 -RunRoot "D:/AI/hotclip-runs/full-20261116"
```

支持一次传入多个已分析录播目录。`GET /api/projects` 返回项目 ID，可用 `/?project=<id>` 打开对应项目。当前版本的素材接入入口是分析目录，不是浏览器上传器；录播结构化与模型校核仍由现有分析工作流完成。

每个目录需要：

- `source.json`：原视频路径、文件大小和媒体元信息。
- `selection/interest-candidates.json`：全片兴趣点与建议边界。
- `audit/reviewed-lines.json`：含稳定 ID、原始 ASR、校核文本、时间和疑点的逐句记录。
- `audit/danmaku.json`：可选；直播背景及带原片时间的弹幕事件。

## 操作流程

1. **选片段**：右侧兴趣点与全片时间轴联动。点击兴趣点，在下方局部精调区拖动入点、出点；点击拨钮上方的时间标签可输入 `HH:MM:SS.mmm` 并跳转。拨钮支持方向键。试听入点播放前 10 秒，试听结尾播放末 5 秒，均自动停在选区内。
2. **加入输出列表**：切片有独立的标题、范围和字幕副本。点击队列条目重新调整，更新后保留已有文字修订。可调整顺序或移除。未可靠定位的标记只打开前后 15 秒供试听，必须人工确认范围后添加。
3. **字幕审核**：左侧切换切片，中央播放，右侧逐句查看。点击画面字幕直接编辑；右侧可改文本、改起止时间、查看 ASR 原文及校核原因、回听前后 1 秒并确认此句。未确认疑点会在导出页提示，但不会强制阻止导出。
4. **导出设置**：选择画质/码率、原片/1080P/720P、是否压字幕、是否压直播弹幕。点击“开始导出”才会真正生成切片视频。任务支持进度、取消、下载和失败后重新提交。

修改自动存入该录播目录的 `studio/draft.json`，切换页面和刷新不会丢失已加入队列的切片、字幕及设置。原始分析文件不被改写。冲突保存返回 409，页面提示刷新，避免多个页面静默覆盖。尚未加入队列的临时选区不落盘。

## 预览与输出

首次把录播 FLV 中的 H.264/AAC 无损换装为可随机拖动的 MP4；`+faststart` 整理索引期间仍显示准备中。缓存以源文件路径、大小、修改时间签名区分；再次打开复用。需要约一份原视频大小的额外磁盘空间。当前浏览器预览针对 H.264/AAC 录播，其他编码可能需要另行转码。

浏览器通过 HTTP Range 读取本机文件，无需整段下载后播放。播放器使用原片绝对时间，画面、字幕、弹幕、入出点和导出共用该时间基准。滚动弹幕采用 Canvas，暂停和拖动后根据当前时间重建；浏览器与 ASS 共用保守的不相撞轨道分配。仅渲染普通聊天弹幕；高密度超出轨道容量时跳过拥挤条目，不把礼物、舰长事件伪装成聊天。

播放器“弹幕”开关控制预览；导出设置中的“渲染直播弹幕”控制永久压制，二者独立。自动码率使用 x264 CRF 20，按实际画面复杂度分配；高画质 CRF 17，小体积 CRF 25，手动模式按目标 Mbps 编码。保留原比例与帧率，不将低分辨率素材放大；AAC 192 kbps。

每次导出保存到 `studio/exports/<任务ID>/<序号>/`：

- MP4 视频。
- SRT 字幕（去句读标点，保留 `3.5` 等数字表达）。
- 字幕上下文 CSV：原片/片内时间、原 ASR、审核后文字、是否人工确认、疑点、前后句。
- 上下文 JSON：范围、字幕、背景、兴趣点依据与区间内弹幕。

字幕默认从 `asr-raw.json` 恢复声学字词时间，接合已校核文字，按音频停顿、中文词边界、终末地/B站词库及长度约束重新断句。跨 ASR 分段合并短句，标点仅作为软提示，显示及导出仍无句读标点。缺少字词数据时保留原字幕并标记需对齐。

审核页“按原声对齐并重新断句”仅处理当前切片，使用本机 Qwen3-ForcedAligner-0.6B，约 24 秒窗口加两侧余量；进度可见、可取消，缓存位于 `studio/alignment-cache`。模型结果缺少足够文本锚点时保留原字幕；极短虚词可能只有邻近锚点插值，会明确标为待回听，不能当成逐字都已精确定位。对齐过程中若编辑了同一切片，返回结果不会覆盖新编辑。对齐会重置该区间人工确认状态。

时间始终保留原片绝对秒数：`subtitleSource` 保存未裁切的字幕副本，`subtitles` 仅表示当前切片可见范围。缩短后再拉长会恢复先前编辑；有字词锚点时同时裁文字，切到发音内部显示疑点。修改字幕文字会使原词时间失效，需按原声重新对齐。导出只在最后一步减去一次切片入点。

这不是声纹分离或语义 LLM 的全片复审。游戏角色与主播重叠、文本本身缺词、极长静音附近的插值等仍需回听。渲染阶段重新编码以实现精确入出点，不采用只能贴近关键帧的直接复制切片。

## 运行边界与维护

- 服务只绑定 `127.0.0.1`，校验 Host、Origin 和写接口会话令牌。它是本机工作台，不是公网多用户服务。
- 所有媒体与下载路径均从注册项目和已完成任务的文件清单解析，不接收任意下载路径。
- 草稿原子替换；导出从提交时的快照运行。重启时将残留运行任务标记失败，保留已生成文件供排查，重新提交即可。
- 导出串行调度，浏览器关闭不停止后端任务。取消终止当前 FFmpeg，保留已经完成的片段；未完成的 `.partial.mp4` 不提供下载。
- `tools/start-studio.ps1` 不会接管或停止已有端口上的进程。服务日志位于 `<RunRoot>/studio/server.out.log` 与 `server.err.log`。

## 验证

```powershell
pnpm studio:check
pnpm typecheck
pnpm exec vitest run src/core/__tests__/studio.test.ts
pnpm studio:build
pnpm studio:test
```

浏览器验收默认使用本机 Microsoft Edge（Playwright `channel: msedge`）。生成独立的 12 秒测试视频和分析数据，测试精确入出点、键盘拨钮、草稿恢复、字幕改字与去标点、实际压制/下载、Range、写接口令牌、并发草稿冲突、错误边界拒绝、弹幕 ASS、取消、无障碍与窄屏。测试不会选择或导出用户录播，截图和验收记录保存在忽略提交的 `studio-test-results/`。

前端遵循 `modern-web-guidance` 的 `slider`、`accessibility`、`forms`：原生 range 保留键盘行为、分开书写各浏览器滑块伪元素、使用 CSS 变量传入百分比避免对新 `attr()`/`progress()` 的硬依赖；原生 dialog 管理焦点；分步导航保留草稿，原生表单与可见标签、错误提示和服务端验证配合。


## 只保留主播字幕

播放器叠加字幕、原生 WebVTT、ASS 压制和 SRT 使用同一规则：只显示 `speakerRole=host`。游戏对白 `game` 和归属不明 `unknown`（含未分类）默认不显示；源录播的游戏声音不做静音或分离。主播自己读弹幕、念台词、模仿角色仍属于主播。

审核页默认只列主播字幕，勾选“显示排除与待判句”可回听其他句子，通过原生单选框改为主播、游戏或待判。人工归属随草稿保存，重新断句、修改切片边界和刷新后保留。跨说话人来源不合并字幕，音频强制对齐只处理主播句，排除句保留作上下文证据。CSV 增加说话人、是否进入字幕和归属依据列。

全片审阅工作流末尾自动运行 Sol 6.1 high 的逐句归属，再执行本地声纹比对与上下文复核。对已有分析目录可执行：

```powershell
pnpm exec tsx tools/classify-caption-speakers.mts "D:/AI/hotclip-runs/full-20261116"
```

结果在 `studio/speaker-roles.json`，带原始审核稿哈希，只有内容匹配时才应用。模型结果必须逐 ID 完整覆盖，缺漏或重复会拒绝。判断有误可人工恢复，不删原始转写。新生成角色结果后需重启 Studio 加载。

声纹流程使用本地 3D-Speaker ERes2Net，逐句读取原录播 16 kHz 单声道音频，每句最多取前 8 秒。少于 0.55 秒或近静音不提取向量，少于 1.5 秒标为弱证据；不向相邻话语借音频伪装成可靠长样本。参考组来自多段明确互动文本与游戏对白的语境标签，不是人工注册身份。分别计算与前三个最近参考的平均余弦相似度，再将音频证据、原判断及前后对话送给 Sol 6.1 high：完整复核所有游戏、待判句和音频有冲突的主播句，重点找回短回应、主播读台词和插话。

无时间戳 PCM 缓存先用 `aresample=16000:async=1:min_hard_comp=0.001:first_pts=0` 按媒体时间戳填补/裁去音频间断，再按原片秒数索引；否则长录播直接拼接采样会累积漂移。当前录播未补偿时在 7400 秒测到约 68 毫秒偏差，修正后在 100、7400、14000 秒抽测均小于 0.2 毫秒。用 `tools/verify-voice-audio-clock.mts <RunRoot>` 对比同一时间直接 seek 的音频波形；这验证取样时钟，不代表声纹归属准确率。

余弦分数不是概率，主播为游戏角色配音、模仿、混音仍可能混淆。没有实施人声源分离，无法证实的一句混合内容仍待判。这里的声纹是录播内部音色比对，不宣称验证了现实身份。`studio/voiceprints/` 保存语境基线、可续跑的特征、参考句、逐句证据、变化报告及 `声纹与上下文复核.csv`。缓存绑定音源路径/大小/修改时间、模型内容、句子时间和语境基线。

只运行声纹复核可用 `pnpm exec tsx tools/review-caption-voices.mts <RunRoot> [ModelsRoot]`。模型默认在 `%APPDATA%/hotclip/models`，缺失会下载；中断后可复用已完成特征及模型请求，完整成功前不替换生效的角色结果。

## 精细时间轴与播放快捷键

- 局部时间轴滚轮以鼠标指向的时间缩放，最小视窗 1 秒；Shift＋滚轮或水平滚轮平移，也可拖动底轨。Ctrl/Meta＋滚轮留给浏览器缩放。
- 视窗与选段边界独立，拖动拨钮时不自动追着边界缩放。Shift＋拖动减速到十分之一；方向键移动 0.01 秒，Shift＋方向键移动 0.001 秒。毫秒是编辑数值精度，视频显示仍受原片帧率限制。
- “适合选段／全片范围／定位入点／定位出点”恢复可见范围；时间标签仍支持精确输入。缩放和平移只改变视窗，不更改字幕或弹幕时间。
- 空格/K 播放暂停，左右键前后 5 秒（Shift 为 1 秒），J/L 前后 10 秒，上下键音量，M 静音恢复，F 全屏，C 字幕，D 弹幕，逗号/句号暂停并按帧率步进。
- 输入框、字幕编辑、时间轴拨钮和打开的对话框优先处理自己的按键。播放器下“播放快捷键”可查看说明或关闭快捷键，避免单字符按键干扰辅助输入。
